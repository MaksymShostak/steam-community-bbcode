# Historical SDLC adoption evidence

These files preserve the standalone repository's former SDLC adoption and verification records, including the original import manifests and MIT notice.
They are historical evidence, not active setup instructions, policy, approval or current verification results.
The files were copied byte-for-byte from `docs/sdlc/` and `.sdlc/` when repository-owned controls were removed on 15 September 2026.
Paths and status statements inside them describe the original adoption snapshot.
The removed implementation and policies remain available in Git history at `093f35a`.

The removal follows ONI commit `0a94775aa143df76131c29768079da6f58484436` while retaining this repository's package tooling, Python prose formatter, runtime/mutation qualification and CodeQL coverage.
Extraction plans, migration records, local `.sdlc/runtime/` evidence and recovery material remain preserved.
Repository-local generated SDLC activation is removed separately from those records.
